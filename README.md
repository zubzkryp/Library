## Library App

A simple browser based library manager built with vanilla JavaScript

# Live Demo
https://zubzkryp.github.io/Library/

# Features

- Add books with title, author, page count, and read status
- Toggle read status of any book
- Remove individual books from the library
- Clear the entire library at once


# Built With


- HTML & CSS
- Vanilla JavaScript
- Object-Oriented Programming — class syntax, static methods, and instance methods


# What I Learned

- Refactoring constructor functions to ES6 classes
- Separating concerns across two classes (Book and Library)
- DOM manipulation and event delegation
- Using dataset to attach unique IDs to DOM elements and retrieve them via e.target.dataset during event handling.
